## 2. 技术路线（三代演进）

### 第一代：MVP（本机 CPU 验证可行性）
- 双编码器（ESM-2 8M 肽 + ESM-2 8M 靶）+ BAN 双注意力 + 分类头
- 3 折 CV AUC **0.663**；验证了数据管线、L_align 对齐损失、评估协议

### 第二代：650M 集群基线
- LassoESM 650M（肽）+ ESM-2 35M（靶），解冻 1 层 + 冻结策略
- 5 折 stratified CV AUC **0.594**（低于 8M MVP，说明小数据下大模型更难训）

### 第三代：改进方案（I1+I2+I5）
| 改进 | 内容 | 实测效果 |
|---|---|---|
| **I1 课程学习** | Bernett 通用 PPI 2 万对预热 → LPI 微调 | **单独无效**（0.566）|
| **I2 硬负样本** | 同靶 × 其他家族肽（逼模型学兼容性）| 与 I5 合用后 0.8145 |
| **I5 结构对齐损失** | 复合物接触图监督 BAN 注意力 | 同上 |
| 组合 | I1+I2+I5 | **stratified 0.8145 ± 0.017**（疑似泄漏）|

**关键科学问题**：I2 的硬负样本与正样本**共享同一个肽**（该肽在靶 A 是正、在靶 B 是硬负）→ StratifiedKFold 不隔离肽 → 模型可"记住肽身份"作弊 → **必须用 grouped CV 重评**（已提交 `grp`，首轮 0.761）。

## 3. 数据资产建设

| 数据 | 规模 | 用途 | 来源 |
|---|---|---|---|
| Lasso 已知互作正样本 | 40 条（312 对锚定对）| 训练正样本 | 文献 + RCSB 核验 |

| Bernett 通用 PPI | 50k → 20k 子集 | 课程学习预热 | Bernett et al. |
| **Propedia 实验复合物** | **2500 个 PDB** | 对接 + 迁移学习 | Propedia v2.3 |
| **实验亲和力数据** | **4321 对**（Ki/Kd/IC50）| **回归标签** | BindingDB + ChEMBL |
| LassoPred 库 | 4749 条 | 拓扑注释 + 判定器正样本 | LassoPred 补充材料 |
| 判定器负样本 | 20000 + 匹配版 10559 | 判定器训练 | UniProt 细菌蛋白 |

**数据特性洞察**：
- PDBbind 已不可用（域名易主 + pdbbind-plus 付费墙）→ 改用 BindingDB/ChEMBL（后者无 `molecule_type='Peptide'`，需按 MW ≤ 10 kDa 从 `'Protein'` 里筛）
- Propedia 的价值：**每对都是实验解析的复合物**（已知结合 + 真实构象）→ 对接盒可用肽自身坐标，远比盲对接可靠

## 4. 核心实验成果

### 4.1 分类预测
| 实验 | AUC | 状态 |
|---|---|---|
| 8M MVP | 0.663 | ✅ |
| 650M 基线 | 0.594 | ✅ |
| I1 单独 | 0.566 | ✅（无效）|
| 全套改进 stratified | 0.8145 | ⚠️ 泄漏待验证 |
| 全套改进 grouped | 0.761（中途）| 🟡 训练中 |

### 4.2 分子对接（结构验证）
- **Lasso 矩阵**：11 肽 × 10 靶 = 110 对（`dock_matrix_full.csv`）
- **关键对照**：CTRL_9KDF（RES-701-3 redocking 回 ETB）**−12.2 kcal/mol**（盒放大后；放大前为 +104.8 假正值）
- **阳性发现**：EDNRB 列（RES-701-3 −14.5）、POLR2A 列（MccJ25 −15.8）
- **盒大小是决定性的**：小盒（< 30 Å）对大环肽产生**假正值**（+37 ~ +360）

### 4.3 模型 × 对接融合（re-ranking）
| 方案 | 已知对平均排名 | 前 20% 命中 |
|---|---|---|
| 模型单独 | 4.43 | 4/8（50%）|
| 对接单独 | 4.14 | — |
| **融合（w=1.0）** | **3.57** ✓ | 4/8 |

- Spearman ρ = **−0.091**（两法不相关 → **信息互补**，融合有增益）
- **未达验收 70%**；失败主因：PB1m7（人工嫁接肽，模型盲点，排 11/11）

### 4.4 Lasso 判定器
- 初版 5 折 CV：F1 0.9730 / AUC 0.9980 —— **虚高**
- **根因（已证实）**：初版负样本长度（100–500 aa）与正样本（20–50 aa）完全不重叠 → 模型学的是"长度捷径"
- **修复**：重建匹配负样本（序列打乱 + 前导肽 + 同长度细菌蛋白，10559 条）→ 重训
- **诚实结果**：CD-HIT 去重后（正 1697 / 负 4414，训练 4888 对），**Val F1 = 0.7863**（最佳 epoch 4）
- 当前 `checkpoints/best_model.pt` 即此诚实版本；集成方式：上游 LassoPred 零改动（`prp49/lasso_id.py` 适配层）
- **方法论教训**：构建负样本时必须匹配正样本的长度/组成分布，否则指标毫无意义（F1 从 0.973 跌到 0.786）

## 5. 科学洞察

1. **刚性对接对长肽的区分度极低**（全部落在 −9 ~ −16 kcal/mol）——大肽接触面积大，范德华项主导，靶特异性被淹没。这不是代码 bug，是方法固有局限。
2. **盒尺寸必须匹配配体大小**：这是本轮最大的方法论教训（假正值全部来自小盒）。
3. **模型分与对接分不相关（ρ≈−0.09）但融合有增益**——说明两者捕捉不同信息（序列模式 vs 几何互补），融合是正确方向。
4. **人工设计肽（PB1m7 嫁接肽）是 pLM 的盲点**——训练集里没有这类序列，模型无法外推。
5. **小数据（312 正）下大模型不必然更好**：650M 基线（0.594）< 8M MVP（0.663）；改进来自"数据构造"（硬负样本）而非"模型规模"。
6. **评估协议决定结论**：同一模型 stratified 0.8145 vs grouped 0.761 —— 泄漏可以让数字虚高 0.05+。

## 6. 工程教训（按代价排序）

| 教训 | 代价 | 修复 |
|---|---|---|
| CSV 行尾 CRLF | 3 次全批失败（对接）| `newline='\n'` + 上传后 `sed` |
| pep/rec 文件名冲突 | 一批全失败 | 前缀区分 |
| 回归任务误用 BCE | 一次训练作废（loss −790）| Huber 回归损失 |
| 模块版本不同步 | 一次训练失败 | 上传代码时整套同步 |
| GroupKFold + 同组负样本 | AUC = nan | 组 id 唯一化 / stratisfied |
| 对接参数不经济（盒大 + exh 8 + 单核）| 2.2 小时仅 398/2499 | 盒 44 Å + exh 4 + 2 核（提速 12–20×）|
| 硬负样本引入肽级泄漏 | 主结果可信度受质疑 | grouped CV 重评 |
| 判定器长度捷径 | F1 虚高 | 匹配负样本重训 |

## 7. 与验收标准的差距

| 标准 | 目标 | 现状 | 差距 |
|---|---|---|---|
| CV AUC | ≥ 0.75 | 0.761（grouped，中途）/ 0.8145（stratified）| ✅ 大概率达标（待终值）|
| 已知对 top-20% | ≥ 70% | 50%（4/8）| ❌ 需改进（对接融合 or 更多已知对）|
| 扫描矩阵 | ≥10 肽 × ≥10 靶 | 13 × 11 | ✅ |
| 端到端 pipeline | 可跑 | ✅ | ✅ |
| 高成药候选 | 清单 | 🟡 待 2499 对对接完成 | 进行中 |

**已知对仅 8 个、排名池仅 10–11 个靶 → 统计上不稳健**，是当前最大的方法论弱点。建议扩大已知对集合（文献再挖 + 家族同源对），或改用更稳健的指标（如 MRR、富集曲线）。

## 8. 未来方向（按性价比）

1. **对接数据规模化**（进行中，2499 → 目标 5000+）：既是回归标签来源，也是"结构证据"来源
2. **回归模型**：4321 实验标签（Ki/Kd/IC50 混用需谨慎，建议分层或按类型加权）
3. **判定器可信化**：匹配负样本复验 + 对照集（随机/打乱/非 Lasso 天然肽）
4. **融合策略升级**：目前是线性 z-score 融合；可试 learning-to-rank 或把对接分作为模型输入特征
5. **成药面板**（41 靶）：回答"哪些 Lasso 肽命中成药口袋"
6. **多构象对接**：单构象刚性对接区分度低 → 每肽多构象（同源建模 + 短 MD）可能提升结构证据质量
7. **拓扑标签特征（II2）**：已设计（ring/loop/tail one-hot 注入肽嵌入），尚未训练验证
