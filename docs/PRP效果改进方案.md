# PRP49 效果改进方案（基于全部实证数据的诊断与路线）

> 日期：2026-09-10（首轮 GPU 训练 + 对接实验完成后）
> 输入证据：8M MVP 本机实验、650M LassoESM 首轮 HPC 训练、S1 预热、环消融、10×10 扫描、81+30 对对接矩阵、融合分析

---

## 一、实证证据汇总（全部为已跑出的硬数据）

| 实验 | 结果 | 含义 |
|---|---|---|
| 8M MVP 分层 CV | **AUC 0.663**（分组 0.641，打乱标签 0.502） | 小模型的弱信号基线 |
| **650M LassoESM 首轮 CV** | **AUC 0.594 ± 0.046**（overall 0.590） | **大模型反而更差 −0.07** |
| 序列打乱对照 | 0.663 → 0.656（几乎不变） | 模型主要靠**氨基酸组成**（捷径） |
| 家族迁移 | 同族/同源 60–88% vs 无关 2.5–15% | 只在"序列近邻"内可迁移 |
| LOFO 跨家族留出 | AUC ≈ 0 | 跨家族泛化不存在 |
| S1 预热（Bernett 2 万对，双 35M 冻结） | CV **0.639** | BAN 能学到通用互作表征 |
| L_align 标签覆盖率 | **8 / 1248 对 = 0.6%** | 结构先验几乎没起作用 |
| 对接矩阵（81 对） | 分数区间 −9 ~ −16（区分度低） | 长肽刚性对接信息量有限 |
| 模型分 vs 对接分 | Spearman **−0.109**（p=0.37） | 两者不一致（互补或都弱） |
| 融合排序扫描 | 已知对平均排名 **3.25 → 2.00**（w↑） | **融合有增益趋势**（n=4，未达显著） |

## 二、失效模式诊断（五个根因，按影响排序）

### F1. 数据量 vs 模型容量严重失配（核心）
312 正样本 / 1248 对训练数据 vs 6.5 亿参数（LassoESM 650M）。8M 模型反超 650M 是**教科书式的过拟合信号**——不是"模型不够强"，而是"数据撑不起大模型"。

### F2. 捷径学习未被阻断
打乱序列对照几乎不变（0.663→0.656）说明决策边界主要由**氨基酸组成分布**刻画，而非界面规则。当前负样本（随机重配对 + 打乱肽）不足以迫使模型学序列顺序。

### F3. 结构先验通道几乎空转
L_align 只有 8 对有效标签（0.6% 覆盖率），λ=0.1 下对 1248 对的训练几乎无影响。规划中"注意力对齐 = 可解释性核心"目前是空承诺。

### F4. 课程学习链路未接通
S1 预热 ckpt（CV 0.639）已产出，但 L2 微调的 BAN 仍是**随机初始化**——三级课程学习的 S1→S2 衔接从未执行。

### F5. 训练目标与项目目标错配
训练用二分类 BCE，项目真正要交付的是**靶标内排序**（"已知互作进前 20%"）。全局 AUC 既难提升也不是有效叙事。

## 三、改进路线（分层：立即 / 短期 / 中期）

### 第一层：立即执行（零到低 GPU，1–2 天）

| # | 措施 | 做法 | 预期 | 判据 |
|---|---|---|---|---|
| **I1** | **接通课程学习** | `train.py` 加 `--init_ckpt`：加载 warmup fold 权重初始化 BAN+头，再跑 L2 | +0.03~0.08 | CV > 0.594，且 ≥ 8M 的 0.663 |
| **I2** | **目标与评测对齐排序** | 损失加 pair-wise ranking 辅助项（同靶内正对 > 负对）；主指标改 per-target ranking | 叙事与指标同时改善 | 已知对进前 20% 比例 ≥70% |
| **I3** | **多容量 + 多 seed 集成** | 8M/35M/650M × 3 seed 打分 z-score 平均 | +0.02~0.05（降方差） | 集成 CV > 单模型最佳 |
| **I4** | **L_align 覆盖率提升** | 同源家族对复用结构矩阵：RES-701-1←9KDF、Capi-var1←6N61、PB1m7←7VF3、变体继承母体 → 覆盖 8 → 40+ 对 | λ 真正生效 | 移除 L_align 后指标下降（证伪"对齐过拟合"） |
| **I5** | **难负样本重构** | ① 同家族肽 × 非同源靶 ② 对接分极低对（对接矩阵已产出） ③ 组成匹配但顺序打乱的"最难负" | 阻断 F2 捷径 | 打乱序列对照 AUC 应显著下降 |
| **I6** | **对接分学习式融合** | 用 logistic/小 MLP 学 (model_score, dock_score) → 融合分（替代手调 w） | 排序增益稳健化 | 融合后已知对排名优于单用 |

### 第二层：短期（数天，中等 GPU/数据工作）

| # | 措施 | 说明 | 预期 |
|---|---|---|---|
| II1 | **数据扩充** | Propedia 人靶子集（L1 唯一缺口）+ PDBbind 肽复合物（亲和力回归）+ RCSB 短肽复合物扩到 2000+ | 数据翻倍是打破 F1 的唯一直接手段；+0.05~0.10 |
| II2 | **拓扑标签特征** | ring/loop/tail/plug one-hot 拼入肽侧嵌入（规划标★★★必做，0.5 人天） | +0.01~0.03，且给消融提供锚点 |
| II3 | **对比学习** | 同族变体拉近、负对推远（InfoNCE），提升家族迁移 | 家族迁移 60–88% → >90% |
| II4 | **多构象对接** | 每肽 3 构象（实验/LassoPred）取最优；柔性环区 | 对接区分度提升，融合增益更稳 |

### 第三层：中期（架构与闭环）

| # | 措施 | 说明 |
|---|---|---|
| III1 | 靶标条件化 BAN（条件注意力） | 扫描场景"固定靶标池"天然适配；TUnA 可借鉴 |
| III2 | 主动学习 + 湿实验闭环 | Top 候选 SPR/BLI 验证 → 阳性扩正样本、阴性做确证负样本（1 轮 3–5 对即可翻倍正样本） |

## 四、推荐执行顺序（未来 1 周）

```
Day 1（今天）  I1 课程学习接通 + I4 L_align 扩覆盖  → 立即重训一轮（~5 GPU·h）
Day 1-2        I2 排序损失 + I5 难负样本            → 第二轮重训（~5 GPU·h）

Day 3-5        II1 数据扩充（Propedia/PDBbind）     → 第三轮训练（数据翻倍）

```

**每轮的固定对照**：8M baseline（0.663）、打乱标签（0.502）、打乱序列（0.656）、以及"移除新增组件"的消融——保证增益可归因。

## 五、判据与风险

- **成功判据**：分层 CV ≥ 0.70 且 ≥ 8M 基线；已知对进靶标前 20% ≥ 70%；环消融显著（已具备：89% + p=0.0059）
- **最大风险**：F1 是数据问题，前两层措施只能把指标推到 ~0.65–0.70；**要突破 0.75 必须靠 II1 数据扩充或 III2 湿实验闭环**
- **诚实声明**：若数据扩充后仍 < 0.70，应转向"结构辅助 + 排序交付"叙事（对接融合已显示该路径可行）
