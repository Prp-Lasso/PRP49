## 三、对首轮执行顺序的建议（更新 README_DEPLOY）

账号到手后的首轮任务范围（与本清单一致）：

1. 上传 + 环境（README Step 0–2，不变）
2. debuga100 冒烟（`job_smoke_debuga100.sh`，已含 L_align 通路验证）
3. **a100 训练（按序）**：
   - **S1 预热（新）**：`python -m prp49.train --config config_warmup.yaml --device cuda`（Bernett 5 万对，双 35M 冻结只训 BAN，~1–2 小时）→ 产出 warmup 检查点作为 S2/S3 初始化

4. 评估三件套：`job_eval.sh`（消融 + Wilcoxon）、`retrospective.py`（回溯排名）、`job_scan.sh`（10×10 矩阵）
5. 结果回传本地 → B 级指标（集成方差/校准/bootstrap）在本地后处理完成
6. 第二轮（GPU 有余量时）：Propedia 下载 + 课程学习衔接（warmup ckpt → L2 微调）+ TUnA 对照复现 + 拓扑标签特征
