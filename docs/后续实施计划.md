## 阶段 1：LPI 训练数据集构建（2–3 周，核心难点）

### 1.1 正样本（可靠互作对）
- **文献挖掘**已知 Lasso 肽–人靶互作：
  - RES-701-1 × Endothelin B 受体（ETB，GPCR，人）
  - Anantin × ANP 受体 NPR-A（人）
  - Siamycin I/II、RP 71955 等 × HIV-1 gp120/gp160 或 CD4 通路（病毒蛋白，可迁移为病毒-人界面训练样本）
  - 微素 J25、Capistruin × RNA 聚合酶（细菌 β′；人 POLR2 同源蛋白作迁移对象）
  - Lassomycin × ClpC1（分枝杆菌；人线粒体 ClpX/ClpP 作同源迁移对象）
- **结构级正样本**：PDB 中 LaP-蛋白复合物（如 RES-701-1×ETB 复合物）→ 提取真实界面接触，用作注意力对齐标签（思路 2）
- 预期规模：仅 ~10–30 对 → **必须靠迁移学习 + 数据增强**（与思路 1 吻合）

### 1.2 预训练/预热数据（线性肽-蛋白互作，量级大）
- TUnA 自带 bernett / xspecies 数据集（普通 PPI）
- 肽-蛋白复合物结构库（Propedia、PepBDB）→ 序列对 + 接触标签
- 可选：PDBbind / 亲和力数据做辅助回归
- 用途：预热双编码器/BAN 骨架 → 再以 Lasso 小样本微调特异头

### 1.3 负样本与灰色样本（思路 3）
- 不用"未报道=不结合"直接当负样本
- **结构互补性预筛**：对候选 (Lasso肽 × 人靶) 全矩阵先做快速对接（Vina/HDock 或仅用 LassoPred 结构 + 表面互补打分），剔除明显无互补性的对
- 保留"可能结合但无实验证据"的灰色样本 → **PU 学习**（无标签样本按权重参与训练，如 nnPU）
- 硬负样本：随机打乱肽序列（保留氨基酸组成）或非互作肽-蛋白对

### 1.4 数据增强（思路 1）
- 环区保守位点理性随机突变（E→D、S/T 互换、保守替换），模拟进化变体；保留 LassoPred 拓扑注释以过滤"开环致死"突变
- 用 LassoPred 对突变体重新预测拓扑，剔除失去 lasso 构象的变体（保证增强集仍为真 lasso）

## 阶段 2：模型与训练（3–4 周）

### 2.1 架构选型（二选一，建议 A→B 渐进）
- **路线 A（快速，复用 PRP49）**：ESM-2(蛋白) + LassoESM(肽) 双编码器 + BAN 注意力融合 + 回归/分类头
  - 输出改双头：结合概率（BCE）+ 亲和力（MSE/排序损失）
  - LassoESM 采用渐进解冻（先冻结→解冻末层→低秩适配）
- **路线 B（进阶，TUnA 基座）**：TUnA 框架 + LassoESM 替代肽侧 ESM 编码器；利用其 uncertainty 输出做候选排序
  - 预热：bernett/xspecies 上跑通 TUnA 基线 → 微调 Lasso 数据

### 2.2 注意力对齐损失（思路 2）
- 对有结构的 LaP-靶复合物（或 AF-Multimer 预测）提取界面接触矩阵 M
- 在 BAN 注意力图 `att_maps` 上加约束：`L_align = || softmax(att) − M̂ ||`（接触残基对高权重、非接触低权重）
- 弱监督、仅在含结构标签的批次启用（权重 λ 调参）

### 2.3 训练配置
- 小样本防护：权重衰减、dropout、早停、K 折（结构已知的 28–48 条按 PDB 分层）
- 复现 LassoPred 的 10-fold 划分思路（MOESM4 可直接参考）

## 阶段 3：评估体系（1–2 周）

- 常规指标：AUC / AP / 精确率-召回（分类）；R² / RMSE / Spearman（回归）；10 折 CV 报告均值±标准差
- **环依赖消融（思路 4，本项目特色指标）**：
  - 对每条测试肽生成"开环"突变体（Isopeptide 位点 E/D→S，破坏索套成环）
  - 同蛋白靶下比较打分：Δscore = score(lasso) − score(open)；预期显著为正且分布分离
  - 对照：远端非关键残基突变（打分应基本不变）→ 证明模型学到的是"环拓扑"而非序列扰动敏感
- 注意力可视化：注意力图 vs 拓扑注释（ring/loop/tail 区域富集检验）；vs AF-Multimer 接触图重叠度
- 基线对比：ESM-2(通用) vs PeptideESM vs LassoESM 三组肽编码器（LassoESM 仓库已有对比脚本可参考）

## 阶段 4：高通量扫描与成药候选（2 周）

- **扫描矩阵**：≥10 条代表性 Lasso 肽（覆盖不同家族/环长/来源门） × ≥10 个人类靶标
- 靶标选取建议（结合已知活性 + 成药性）：
  GPCR（ETB/EDNRB、NPR-A、PAR1）、酶（RNA 聚合酶 II POLR2A、HIV-1 整合酶/逆转录酶、人线粒体 ClpP、凝血酶）、蛋白-蛋白界面（MDM2-p53、PD-1/PD-L1 同源界面）、离子通道
- 输出：LPI 矩阵（概率 + 亲和力 + 不确定性）→ 排序 Top 候选
- 成药性过滤：LassoPred 结构稳定性（plug 评分）、Cys 数（合成难度）、质量/亲水性（口服 vs 注射）、与 TUnA uncertainty 结合
- 交付物：候选互作对清单 + 每个候选的（序列、预测结构、靶标、打分、理由）→ 供湿实验验证

## 主要风险与对策

| 风险 | 对策 |
|---|---|
| 正样本极少（~10–30 对） | 迁移学习预热 + 数据增强 + 半监督/PU；评价以排序/消融为主而非绝对精度 |
| 无 GPU 或显存不足 | LassoESM 650M 仅嵌入需 ~4–8 GB；可降级 PeptideESM 650M→t33 或 CPU 批次小跑；必要时用 35M/150M 蒸馏替代 |
| LassoPred 官网 API 403 | 已用论文 Source Data 落盘（4749 条），管道全部本地化 |
| Vina 对接标签有偏 | 仅作预筛/灰色样本来源，不作为唯一训练标签；主标签用文献正样本 + PU |
| 人类靶标结构缺失 | AF2/AF-Multimer 预测补结构；无结构时用序列级注意力对齐 |
