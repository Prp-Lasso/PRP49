## 0. 一句话摘要

项目所需的前置数据、模型与文献调研已全部完成：**4749 条带拓扑注释的 Lasso 肽数据库已落盘、LassoESM 专用语言模型权重已下载、正样本/可迁移同源样本的文献证据链已建立**。下一步进入训练前，需要课题组确认**计算资源**（GPU 规格/服务器）与 4 项技术决策。

### 2.3 文献调研结论（三条线并行完成，证据已分级）

**① Lasso 肽×人类蛋白直接互作证据极少（正样本的现实约束）**：

| 互作对 | 证据 | 结构 |
|---|---|---|
| RES-701-3 × 人 ETB 受体 | ★★★ cryo-EM 复合物（Nat Commun 2025） | **9KDF**（已核验与库内 LP_434 序列一致） |
| RES-701-1 × ETB | ★★ 选择性拮抗生化数据 | 经 9KDF 同源迁移 |
| PB1m7/PB1m6A9（lasso 嫁接肽）× 人 Plexin B1 | ★★★ X 射线复合物（Structure 2022） | **7VF3 / 7VG7** |
| Anantin × NPR-A；Propeptin × PREP | ★★ 竞争性拮抗/酶抑制 | 无结构 |
| Chaxapeptin/Sungsanpin/Ulleungdin/Sphingopyxin I × 癌细胞 | ★ 仅表型（靶标未鉴定） | 无 |

**② 可迁移同源样本（分层接受）**：
- **高价值**：MccJ25/Capistruin × 细菌 RNAP 次级通道（6N60/6N61）→ 人 POLR2A，桥螺旋界面跨域保守，且有 α-amanitin（双环肽）× 人 Pol II 复合物（6EXV/3CQZ）作同界面锚点；**新发现** Lariocidin × 70S 核糖体（9DFC/D/E，2024）→ 人 80S 核糖体 PTC
- **中价值**：Lassomycin × ClpC1 → 人 CLPB/CLPX（AAA+ 核心保守、NTD 界面不保守）
- **排除**：Siamycin × HIV Env（无人类同源物）
- **扩充池**：跨拓扑环肽-人靶复合物（CsA-PPIA、FK506-FKBP12、compstatin-C3、RGD 环肽-整合素等，数十~数百对）

**③ 可复用公共数据**：Propedia（~1.9 万肽-蛋白复合物）、PepBDB、PDBbind 肽子集（~2458 肽复合物，含亲和力）、TUnA Bernett/XSpecies（PPI 预热）、BioGRID/IntAct 肽条目、DBAASP/DRAMP/CyBase（肽语料）。

### 2.4 关键判断

> 纯 Lasso 直接正样本仅约 4–10 对，**无法支撑端到端监督训练**。
> 因此技术路线必须采用"**三级课程学习**"：通用肽-蛋白互作预热 → 环肽-人靶迁移（带拓扑标签）→ Lasso 小样本微调 + 结构先验弱监督（注意力对齐损失）+ 环依赖消融评估。这一判断与项目申报书中的迁移学习思路完全一致，且已获得具体数据支撑。

## 3. 技术路线（四个已识别问题 → 对策 → 现状）

| # | 问题 | 对策（申报书思路） | 调研后落地的具体方案 |
|---|---|---|---|
| 1 | 正样本稀少、过拟合风险 | 预训练+微调迁移学习 + 环区理性突变增强 | 三级课程学习：TUnA Bernett/Propedia（预热）→ CsA/FK506/amanitin 等环肽-人靶复合物（迁移，带拓扑标签）→ 9KDF/7VF3 等 Lasso 结构对（微调）；增强突变用 LassoPred 拓扑注释过滤"开环致死"变体 |
| 2 | 注意力物理可解释性不足 | AF-Multimer 接触标签 + 注意力对齐损失 | 用 9KDF/7VF3/6N60/6N61/9DFC 提取真实接触矩阵作对齐标签；AF-Multimer 仅需补跑无结构的对（Anantin-NPR-A 等 5–10 对） |
| 3 | 负样本假阴性偏误 | 结构互补性预筛 + PU 学习 | HDOCK/HPEPDOCK 对接预筛生成"灰色样本"；nnPU 加权训练；硬负样本=序列打乱对照 |
| 4 | 评估单一，难验证环构象特异性 | 环依赖消融评估 | 利用数据库 Isopeptide 位点注释自动生成 E/D→S "开环"突变体，比较 lasso vs 开环打分；对照远端突变 |

**模型架构**（沿用 PRP49 雏形演进，待确认）：蛋白侧 ESM-2 + 肽侧 **LassoESM** + BAN 双线性注意力融合 + 双头输出（结合概率 + 亲和力）。TUnA 作为对照基线与不确定性模块来源。

## 4. 需要的资源

### 4.1 计算资源（量化申请清单）

| 用途 | 最低配置 | 推荐配置 | 说明 |
|---|---|---|---|
| ESM-2/LassoESM 嵌入与训练 | 8 GB 显存 GPU | **16–24 GB（如 RTX 3090/4090 或 A4000/A5000）** | LassoESM 650M 冻结推理 ~4–8 GB；解冻末层微调 ~16 GB+ |
| AlphaFold-Multimer 接触图（5–10 对） | — | 16 GB+ GPU 或 ColabFold 云 | 仅少量结构对，可分批或借学院服务器 |
| 快速对接预筛（灰色样本） | 8 核 CPU | 16–32 核 CPU 或 HPC 队列 | Vina/HDOCK，10 肽×520 蛋白≈5200 次任务，可并行 |
| LassoPred 结构预测（10 条扫描肽） | 8 核 CPU + Linux | 课题组 Linux 服务器（需 Amber+PyMOL） | 每条 ~10 分钟，仅跑扫描集 |
| 存储 | 50 GB | 100 GB+ | 模型权重 + 嵌入缓存 + 对接输出 |

**方案选项**（供讨论）：
- **A**：本机升级/自有 GPU（16GB+）+ 学院 Linux 服务器做对接与 LassoPred
- **B**：全部走学院/学校 HPC 队列（需要 SLURM 账户）
- **C**：云端租用（AutoDL 等，RTX 3090 约 1–2 元/小时；本项目约需 200–400 GPU·小时，预算 ~500–1000 元）

## 6. 需要决策的事项（请老师/组员确认）

1. **计算资源**（本文件 4.1）：选方案 A/B/C？（这是当前唯一阻塞训练的因素）
2. **正样本口径**：是否接受"细菌 RNAP/核糖体→人同源物"迁移（高价值）与"跨拓扑环肽-人靶复合物"（如 CsA-PPIA）进入训练集？建议接受并带权重；病毒靶标建议排除
3. **路线确认**：以 PRP49 现有架构（ESM-2+LassoESM+BAN）为主线、TUnA 作对照基线的方案是否认可？
4. **靶标与扫描肽清单**：建议的 10 靶标（EDNRB/PLXNB1/POLR2A/PPIA/FKBP1A/NPR1/C3/MDM2/整合素 αVβ3/CLPB）与 10 条扫描肽（RES-701-3/MccJ25/Capistruin/Anantin/Siamycin I/Chaxapeptin/Sphingopyxin I/Ubonodin/Lassomycin/Lariocidin）是否调整？
