# 家族同源性建模：现状、能力边界与候选方案

> 问题：项目目前如何建模"肽家族/靶标家族的同源性"？
> 简答：**目前以隐式建模 + 评估导向为主，尚无显式的家族同源性模型**。
> 本文件梳理已实现的机制、MVP 实测的能力边界，以及下一步可选的显式建模方案。

---

## 一、现状：家族同源性被如何"处理"（三个层次）

### 层次 1：数据标注（家族作为分组标签）
- 正样本带 `group` 字段（RES701 / RNAP / ANANTIN / TRY / ITG / MDM2 / CLPC / PB1 / C3 / FhuA）
- 负样本构造"同池重配对"隐含一个假设：**家族信息在肽与蛋白的序列本身里**，负样本不保留家族一致性（打乱配对即破坏家族匹配）
- 环区保守突变增强隐含第二个假设：**家族内保守替换保持互作**（E↔D、I↔L↔V、S↔T、F↔Y）

### 层次 2：评估协议（家族作为泛化边界）
- **LOFO（leave-one-family-out）**：每次留出一整个肽家族做测试——度量"跨家族泛化"
- **GroupKFold（按 pdb / group）**：同家族强制同 fold，防止同族变体泄漏导致 CV 虚高
- **家族迁移实验**（family_transfer.py）：训练一个变体 → 测试同族变体/同源靶标（RES-701-1→-3、牛胰蛋白酶→人胰蛋白酶、capistruin→var1），度量"家族内/同源迁移"

### 层次 3：训练先验（家族作为间接约束）
- **拓扑标签**（lasso/cyclic/bicyclic/disulfide/linear，已规划）：拓扑类别是"家族超类"的粗粒度先验
- **同源迁移对**进入训练集：牛→人胰蛋白酶、RpoC→（α-amanitin×POLR2A）等——把"同源性"当作**样本**喂给模型，而非当作**结构**注入模型
- **注意力对齐损失**（已实现代码）：接触矩阵是"跨家族不变的物理界面约束"——同一靶标家族共享界面模式

**一句话**：家族同源性目前靠 ESM-2/LassoESM 预训练嵌入的序列相似性**隐式承载**，家族标签只用于评估与防泄漏，模型内部没有任何显式的家族/同源结构。

## 二、MVP 实测的能力边界（隐式建模的成绩单）

| 实验 | 结果 | 解读 |
|---|---|---|
| 家族内迁移（同族变体、同源靶标） | **60–88%** 排序能力 | 隐式建模在"序列近邻"内有效——ESM 表示确实承载了家族相似性 |
| 无关家族对照 | 2.5–15%（随机水平） | 超出近邻即失效 |
| LOFO 跨家族留出 | **AUC≈0** | 模型完全无法泛化到未见家族 |
| 序列打乱对照 | AUC 不变 | 家族相似性主要停留在"氨基酸组成"层面 |

**核心矛盾**：下游扫描场景（新家族肽 × 新靶标）恰好全是"未见家族"——而隐式建模在未见家族上的泛化能力实测≈0。也就是说：**当前模型能回答的（家族内变体排序）不是项目要问的（跨家族新互作发现）**。

## 三、显式建模候选方案（5 个）与适用性评估

| 方案 | 思路 | 家族同源性被建模为 | 与项目契合度 | 成本 |
|---|---|---|---|---|
| A. 靶标条件化（target-conditioned） | 把靶标嵌入作为条件注入肽侧编码（类似 TUnA 的 target-aware） | "什么肽适合什么靶标口袋"——家族信息通过靶标侧共享 | ★★★ 扫描场景直接可用（靶标可重见） | 中（改 BAN 为条件注意力） |
| B. 界面原型网络（interface prototypical） | 按靶标家族建立"肽-界面互补模式"原型，测试肽与原型匹配 | 家族 = 界面模式原型 | ★★★ 契合"跨肽家族、共享靶标"的扫描 | 中（原型计算+度量学习损失） |
| C. 同源映射桥接（homology bridging） | 显式训练"细菌靶标→人同源物"的映射（RpoC→POLR2A、ClpC1→CLPB、70S→80S），让模型学会把家族知识"翻译"到人靶 | 同源性 = 可学习的靶标间映射 | ★★☆ 直接利用已有的同源对资产 | 中（需要同源对作为辅助任务） |
| D. 对比学习/度量空间 | 同族变体-同靶对在表示空间拉近，负对推远（InfoNCE 类损失） | 家族 = 表示空间中的簇 | ★★☆ 与 MVP 家族迁移的正信号呼应 | 低（加一个对比损失即可） |
| E. 元学习/少样本适应（MAML 类） | 按家族构造任务分布，学"快速适应新家族"的初始化 | 家族 = 任务 | ★★ 理论优雅但训练复杂 | 高 |

**不推荐**：家族 ID 嵌入（one-hot 家族向量）——新家族无法获得嵌入，与零样本扫描场景直接冲突。

---

## 四、建议组合（按优先级）

1. **D 对比学习（立即，零 GPU 可先在 MVP 验证）**：在当前双编码器后加对比损失，重跑家族迁移实验——若 60–88% 提升到 >90%，说明度量空间建模有效，且几乎不增加训练成本
2. **A 靶标条件化（GPU 阶段主方案）**：把 BAN 升级为条件注意力（肽 query、靶标 context），与"扫描=固定靶标池"的场景天然一致；这正是 TUnA 的可借鉴点
3. **C 同源桥接（辅助任务）**：把已有的同源对（RpoC×POLR2A 等）作为辅助训练信号，让模型显式学习跨物种翻译——这是本项目区别于通用 PPI 模型的特色
4. **B 原型网络（评估/解释工具）**：即使不作为主模型，原型可用于解释"为什么这个肽被预测结合该靶标"（最近原型可视化），强化可解释性叙事

**预期效果**：显式建模后，家族迁移指标应从"近邻内有效"扩展到"同靶标家族内有效"——对应的验收标准是：已知对回溯验证 ≥70% 进入各自靶标前 20%（现有隐式建模下该指标未达标，见正样本局限分析）。
