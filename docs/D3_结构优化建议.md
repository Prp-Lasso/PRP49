# D3 结构优化建议（交付物之二）

> 面向 `results/candidates_final.csv` 前 11 个候选肽的结构改造建议。
> **本轮全部结论的性质**：模型打分是**外推预测**（训练集中没有任何工程化变体），
> 稳定性判断来自**拓扑文献规则**而非计算，均需实验验证。

## 一、饱和突变扫描（job 62657898，4009 个变体）

**设计**：11 条候选肽 × 每个位置 × 19 种替换 = 4,009 个单点变体，
对 4 个靶（POLR2A / EDNRB / CLPB / PPIA）全矩阵打分。
全矩阵而非只打各自靶，是为了让**脱靶列同时充当特异性对照**。

**结构风险标注**：904 个变体被标记——替换掉成环必需的 Cys/Gly、或可能破坏 β-转角
的 Pro 替换。**模型对"大环是否还能闭合"一无所知**，因此这些位点的预测不可直接采用。

产出：`results/mutscan_matrix.csv` + `mvp_cpu/mut_meta.csv`

## 二、环大小调整（job 62657940，33 个变体）

### 设计

对每个候选，以文献拓扑确定**环区**（内酰胺键：N 端 α-氨基 ↔ 环内 Asp/Glu 侧链羧基），
然后：**缩短 1 个残基**、**延长 1 个 Gly**、**延长 2 个 Gly**。

### 稳定性判据（来自拓扑学，非模型）

**7–9 残基的环是允许穿线的窗口**——环太小无法容纳尾部穿过，太大则尾部无法被有效锁住。
因此：

| 变体 | 稳定性判据 |
|---|---|
| ring8→7 / ring9→8 | ✅ 仍在 7–9 窗口内，**穿线可行** |
| ring8→9 | ✅ 仍在窗口内 |
| ring8→10 / ring9→10 / ring9→11 | ⚠️ **超出窗口，穿线很可能失败** |

### 拓扑来源（逐肽标注，避免把预测当事实）

| 肽 | 环区来源 |
|---|---|
| MccJ25 | 文献：内酰胺 Gly1–Glu8，尾部 Tyr9–Gly21 穿环，His5 与尾部形成氢键 |
| Capistruin | 文献：内酰胺 Gly1–Asp9，尾部 Arg10–Asn19 |
| Lassomycin | 文献：内酰胺 Gly1–Asp8，尾部 Gln9–X16 |
| RES-701-1 / RES-701-3 | 文献：9 残基环（RES 系列）|
| **Anantin** | ⚠️ **预测结构**（LassoPred+tleap，8 个 loop-length 模型取中位数）—— **不是实验结构** |
| Siamycin-I / Sphingopyxin-I / Ubonodin / Chaxapeptin / Lariocidin | 默认假设 8 残基环（拓扑未被表征）|

产出：`mvp_cpu/ring_variants.csv`、`ring_meta.csv`、`results/ringscan_matrix.csv`

### 权衡曲线的读法

- **结合**：由模型打分给出（待作业完成）
- **稳定性**：由 7–9 窗口判据给出
- 两条信息**不合并成单一分数**——它们来源不同、可信度不同，合并会掩盖这一点

## 三、尾部修饰建议（可直接交付）

### 3.1 一条关键结构性事实

**Lasso 肽的 N 端 α-氨基已被内酰胺键占用**，因此**常规的 N 端乙酰化/加帽不适用**——
这本身就是 lasso 折叠相对线性肽的**内在优势**：N 端天然被封锁。

**主要蛋白酶攻击面是暴露的 C 端尾部** → **C 端酰胺化是性价比最高的一处改造**。

### 3.2 修饰建议汇总

| 修饰 | 做法 | 机理 | 对结合的影响 | 合成成本 | 优先级 |
|---|---|---|---|---|---|
| **C 端酰胺化** | 末端羧基 → 酰胺 | 移除羧肽酶底物；尾部是主要降解入口 | 通常中性（已知复合物中尾部朝向界面之外）| 极低（标准固相合成）| **高** |
| C 端甲基化 | 羧基 → 甲酯/甲酰胺 | 同上，另一条合成路线 | 中性至略负（酯键易水解）| 极低 | 低 |
| N 端加帽 | **不适用** | N 端已在环内 | n/a | n/a | n/a |
| 尾部截短 | 删除 1–2 个暴露尾部残基 | 缩短可被酶切的片段 | ⚠️ **风险**：尾部负责穿线，截短可能**解穿线、破坏折叠** | 中 | 中低 |
| D-氨基酸扫描 | 尾部残基换 D 型 | 蛋白酶无法切割 D-肽键 | 视残基而定，尾部在外围 | 中（手性合成）| 中 |
| 首尾环化 | 把尾部共价连到环上 | 彻底消除游离尾部 | ⚠️ **高风险**：lasso 退化为普通环肽，**丢失穿线拓扑** | 难 | 低 |

完整逐肽表（含各肽 C 端残基与尾部序列）：`results/tail_modification_advice.csv`

## 四、改造后复验（范围说明，诚实标注）

| 改造类型 | 是否改变主链 | 复验方式 | 状态 |
|---|---|---|---|
| C 端酰胺化 / 甲基化 | **否**（仅换末端基团）| 主链构象不变 → **可沿用现有对接分**；严格做法是修改 PDBQT 后重跑（预期差异 ~0.1–0.5 kcal/mol，不改变排序）| ✅ 结论可直接沿用 |
| 尾部 D-氨基酸替换 | 部分（侧链手性）| 需重建 PDBQT + 重新对接 | ⏸ 未做 |
| 尾部截短 | **是** | 需结构重建 + 对接 | ⏸ 未做 |
| **环大小改变** | **是** | 需结构重建（LassoPred construc_package / ESMFold）+ 重新对接 | ⏸ **建议只对模型打分最优的 1–2 个环变体做**，而非全部 33 个 |

> **为什么不对全部变体做对接**：结构重建 + 对接的成本远高于模型打分，
> 而模型打分的作用本就是**筛出值得做结构工作的少数**。先筛后建，而不是全建。
