## 三、⚠️ 一个可写进论文的方法学对照点

**组员用 `random_split(0.8/0.2, seed=42)`**，而数据是 **243 对 / 32 个蛋白**（平均 **7.6 对/蛋白**）。

→ **随机划分下，同一蛋白（甚至同一肽）会同时出现在训练与测试**，R² 存在**高估风险**。

**本项目的同源经验**（可作论文中的对照证据）：

| 协议 | 本项目 AUC |
|---|---|
| 分层 CV（**有泄漏**）| 0.8145 |
| 按肽分组 | 0.8333 |
| 按家族分组（最严）| 0.8142 |

**建议的对照实验**：用本项目的分组 CV 协议重新评估组员模型，量化"随机划分 vs 分组划分"的 R² 差距。
**这既是对组员结果的诚实检验，也是论文中一个有独立价值的方法学结论。**

## 四、可整合的四个层面（按价值排序）

### 4.1 ⭐ 结构工具互补（本项目缺失，价值最高）

组员的 `translasso.py` + `TailBackbone.py` 提供 **Lasso 肽的尾部穿线结构生成**；
本项目当前用的是 **LassoPred 预测 + tleap**（且 Anantin 等标注为 PREDICTED）。

**整合动作**：
1. 用组员流程为**本项目最终 10 对中的肽**生成结构
2. 与本项目现有结构来源（实验 PDB / AFDB / LassoPred）**三源对比**
3. 对**结构敏感**的候选（本项目已测得 `top-1 一致率仅 1/9`）重跑对接 → 检验排序稳健性

**预期产出**：把"结构来源主导对接结果"这一已知问题，从"发现"推进到"缓解"。

### 4.2 任务互补：分类 + 回归多任务

- 本项目：**是否结合**（概率）
- 组员：**结合多强**（能量）
- 二者共享同一 BAN 主干 → **可做多任务训练**（本项目已有 MTL 实现，跨域迁移经验 +0.172）

**整合动作**：以本项目分类头为主任务，加入组员的回归头作辅助任务，检验是否提升按靶分组 AUC。

### 4.3 数据合并

| 来源 | 规模 | 标签类型 |
|---|---|---|
| 本项目对接 | 122（Lasso 矩阵）+ 99（AFDB）+ 2,161（Propedia）| Vina |
| 组员 | 243 + 26 | Vina |
| **合并** | **~2,650** | 统一 Vina 尺度 |

**注意**：不同来源的 Vina 分**不可直接混用**（本项目已实测：靶间系统性偏差 23.7 kcal/mol vs 靶内 0.92）
→ 合并前必须**靶内标准化**（本项目已有实现 `scratch/fix_within_target_zscore.py`）。

### 4.4 模型集成（输出级）

- 本项目：分类概率（已校准）
- 组员：top-3 R² 快照集成 → 回归值
- **融合方式**：以本项目分类为主判据，回归作**排序内的次级微调**（类似本项目 binding + docking 的两路融合，实测相关性仅 +0.103 → 有互补空间）
