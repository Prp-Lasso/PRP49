## 第一部分：训练规划

### 1.1 数据体系（三级课程学习，L0→L1→L2）

| 层级 | 数据 | 规模 | 用途 | 获取状态 |
|---|---|---|---|---|
| **L0 预热** | TUnA Bernett + XSpecies（通用 PPI）；Propedia 肽-蛋白复合物（人靶子集） | 1–5 万对 | 让双编码器+BAN 学会通用互作表征 | 待下载（HF/官网） |
| **L1 迁移** | 环肽/大环肽-人靶复合物（CsA-PPIA、FK506-FKBP、compstatin-C3、RGD-整合素、双环肽系列）+ RCSB 人蛋白×短肽复合物（MVP 已验证 312 对可扩展至千级） | 1–3 千对 | 迁移到"环肽-人蛋白"领域，**带拓扑标签**（lasso/cyclic/bicyclic/disulfide/linear） | 部分已落盘（mvp_cpu/） |
| **L2 微调** | Lasso 结构/文献正样本（9KDF、7VF3、6N60、6N61、8IBO 等 + 同族变体）+ **环区理性突变增强**（×5–10） | 30–200 对 | 领域适配 lasso 拓扑 | 已落盘 + 增强待生成 |

**增强策略**（思路 1 落地）：
- 环区保守位点理性突变：E→D、S/T 互换、保守疏水替换；每肽生成 5–10 个变体
- 变体过滤：跑 LassoPred 拓扑预测（或按库内 Ring_Length/Isopeptide 注释规则），剔除失去索套构象的"开环致死"变体
- 控制：增强集仅用于训练，评估集只用真实序列

**负样本策略**（思路 3 落地）：
- 软负：同池随机重配对（MVP 已验证该构造可学）
- 灰色样本：HDOCK/HPEPDOCK 结构互补性预筛后"可能结合但无证据"的对，用 nnPU 加权训练
- 硬负：序列打乱肽 × 同蛋白（对抗样本，防止组成级捷径——MVP 已发现 8M 模型主要靠组成级信号）
- 负样本量：正样本 3–5 倍

**防泄漏规则**（写死在数据管道）：
1. CD-HIT 肽序列聚类（阈值 0.5）：同簇肽不得跨 train/test
2. 蛋白侧聚类（阈值 0.4）：同簇蛋白不得跨 fold
3. 同 PDB 条目的对强制同 fold（GroupKFold by PDB）
4. 增强变体与母体同 fold

### 1.2 模型架构与训练配置

```
蛋白序列 ── ESM-2 35M（微调）──┐
                                ├─→ BAN 双线性注意力（v=蛋白, q=肽）→ 融合向量 ─→ 分类头(BCE) + 亲和力头(可选 MSE)
肽序列 ── LassoESM 650M（冻结→渐进解冻末层）─┘
```

| 组件 | 配置 | 说明 |
|---|---|---|
| 蛋白编码器 | ESM-2 t12_35M（微调） | 显存可控；对照组用 t6_8M/t30_150M |
| 肽编码器 | LassoESM（650M，33 层） | 冻结主干→解冻末 1–3 层（渐进） |
| 融合 | BAN（低秩 k=3，头数 3–8） | 输出注意力图 att_maps 供对齐损失与可视化 |
| 损失 | BCE(pos_weight) + λ·L_align + (可选) β·MSE_affinity | L_align 见 1.3 |
| 优化 | AdamW lr 1e-4~2e-3，warmup 5%，cosine 衰减，梯度裁剪 1.0 | 各阶段独立学习率 |
| 正则 | dropout 0.3–0.4，weight decay 1e-4~1e-5，早停 20–25 | MVP 超参起点 |
| 协议 | 每阶段：5 折分层 CV + 按 PDB 分组 CV；3 种子 | 与 MVP 一致，可对比 |

**注意力对齐损失**（思路 2 落地）：
- 标签：9KDF/7VF3/6N60/6N61/8IBO 等复合物提取界面接触矩阵 M（残基对，距离<5Å 或 iAlign 界面定义）；无结构对用 AF-Multimer（若 GPU 预算允许）或跳过
- 损失：L_align = KL(softmax(att_map) ‖ M̂)，仅在有结构标签的批次启用；λ 从 0.1 起步，按验证集调
- 输出：注意力图 + 接触重叠度报告（检验指标之一）

### 1.3 训练流程（三阶段细节）

| 阶段 | 数据 | epochs | 冻结策略 | λ_align | 产出 |
|---|---|---|---|---|---|
| S1 预热 | L0（PPI） | 20–30 | 全冻结编码器，仅训 BAN+头 | 0 | 通用互作表征 + 检查点 |
| S2 迁移 | L1（环肽-人靶） | 50–100 | 解冻蛋白编码器末 2 层 + 肽编码器末 1 层 | 0.1（若有结构标签） | 领域适配模型 |
| S3 微调 | L2（lasso+增强） | 100–200 | 同 S2，可选肽末 3 层 | 0.2–0.5 | 最终模型 |
| S4 评估 | 全部协议+消融 | — | — | — | 结果 JSON + 图表 |

**GPU 预算分配**（对应《GPU资源估算.md》，200 GPU·h 口径）：

| 环节 | GPU·h | 备注 |
|---|---|---|
| 嵌入提取与缓存 | 5 | 一次性 |

| 评估+消融矩阵（CV×种子×变体） | 40–60 | 大头，4 卡可并行 |
| 调参 | 20 | |
| AF-Multimer（可选） | 20–35 | 可移出（ColabFold） |
| 粗筛扫描 | 5 | |
| **合计** | **100–140（申请 200 含冗余）** | |

## 第二部分：目标核算（对照 PRP 预期目标）

| PRP 预期目标 | 量化验收指标 | 可行性依据 |
|---|---|---|
| 1. 开发基于序列的 pLM pipeline | ① 代码模块化（data/model/train/eval/scan 五模块）② 分层 CV **AUC ≥ 0.75** 且按 PDB 分组 CV **≥ 0.70** ③ 显著优于全部基线 | MVP 8M 模型已达 0.66/0.64；换 650M+BAN+对齐损失提升 0.05–0.10 为合理预期（保守） |
| 2. 扫描 ≥10 肽 × ≥10 靶 | ① 输出 ≥100 对打分矩阵（概率+亲和力+不确定性）② 矩阵附证据标注（A 直接/B 同源/C 纯预测）③ 全蛋白质组粗筛（2 万蛋白×代表肽）为加分项 | 扫描仅推理，GPU·h 忽略不计；靶标/肽清单已在决策文档确定 |
| 3. 筛选高成药潜力候选 | ① Top 5–10 候选清单 ② 每项含：序列、LassoPred 预测结构、靶标、打分、成药性 6 维评估、湿实验验证建议 | 成药性过滤规则见 3.5 |
| 4. 创新点：拓扑异构肽高通量互作分析 | ① 环依赖消融：开环突变体打分显著下降（配对 Wilcoxon p<0.05，ΔAUC≥0.10）② 注意力图与真实接触显著重叠（超几何 p<0.05）③ 与对接方法（HDOCK/Vina）Spearman 相关 ≥0.3 | 数据注释（Isopeptide 位点）已具备；消融为推理级计算 |

**时间核算**（GPU 到位后）：

| 周 | 工作 | GPU 依赖 |
|---|---|---|
| W1 | 环境搭建 + 嵌入提取 + S1 预热跑通 | 低 |
| W2–3 | S2 迁移 + S3 微调 + 首轮 CV | 高（连续） |
| W4 | 消融矩阵 + 对齐损失调参 | 高（可 4 卡并行） |
| W5 | 扫描 + 成药性过滤 + 报告 | 低 |
| 总计 | **5 周**（GPU 排队另计）；等待 GPU 期间的零 GPU 工作见第五部分 | |

**失败判据（Go/No-Go，提前声明）**：
- ❌ 若 S3 后分层 CV AUC < 0.65 且不显著优于 8M MVP → 判定"序列信息不足以支撑该项目目标"，转为"结构辅助特征"路线（引入 LassoPred 拓扑特征/对接打分），不继续盲目调参
- ⚠️ 若 AUC 0.65–0.75 → 达标但需在报告中如实标注局限（组成级 vs 构象级信号占比）
- ✅ 若 ≥0.75 且环依赖消融显著 → 按计划推进扫描与候选筛选

## 第三部分：训练完成后的多维度实用性检验

### 3.1 内部统计检验（模型本身）
| 检验 | 方法 | 通过标准 |
|---|---|---|
| 交叉验证 | 5 折分层 + 按 PDB 分组，3 种子 | AUC 均值±std，两组协议都报 |
| 显著性 | 与打乱标签/单侧特征基线做 paired bootstrap（1000 次） | p<0.05 |
| 校准 | 可靠性曲线 + Brier 分数 | 概率可解释 |
| 不确定性 | 集成（种子平均）方差 / TUnA uncertainty 头移植 | 给扫描矩阵附置信度 |

### 3.2 回溯性文献验证（最重要的实用性检验）
- **留出已知互作对**（9KDF RES-701-3×ETB、7VF3 PB1m7×PlexinB1、6N60/6N61、8IBO、CsA×PPIA、compstatin×C3 等，训练时不包含）→ 模型打分
- 报告：**已知对的排名百分位**（在 10×10 矩阵或负样本池中的位置）
- 通过标准：≥70% 的已知对进入各自靶标前 20% 排名；MVP 家族迁移（60–88%）提示该目标可达成
- **文献新增对预测**（前瞻性模拟）：用 2024–2025 新发表的互作对做时间切片盲测（如 lariocidin-核糖体），检验时间泛化

### 3.3 环依赖消融（特色指标，思路 4）
- 对扫描集中的每条 lasso 肽生成：① 开环突变体（Isopeptide 位点 E/D→S，破坏索套）② 远端对照突变体（非关键位点保守替换）
- 检验：score(lasso) − score(open) > 0 的比例 ≥ 80% 且配对 Wilcoxon p<0.05；对照突变打分无显著变化
- 与 LassoPred 拓扑预测交叉验证：LassoPred 判定"失去 lasso 构象"的变体，模型打分应下降

### 3.4 可解释性检验（思路 2 落地验收）
- 注意力图可视化：环/loop/tail 三个拓扑区域的注意力权重分布，检验是否富集于已知结合界面
- 定量：注意力 top-k 残基与真实接触残基的 Jaccard 重叠 + 超几何检验
- 消融：移除对齐损失后重叠度下降 → 证明 L_align 有效
- 案例：RES-701-3×ETB（9KDF 有真实接触）作为旗舰案例出图

### 3.5 与外部方法交叉验证
| 对照方法 | 检验 | 标准 |
|---|---|---|
| HDOCK/HPEPDOCK 对接打分 | 对同一 100 对矩阵算 Spearman 相关 | ρ ≥ 0.3 表明与结构方法一致；不一致处做案例分析 |
| LassoPred 结构预测 | 高 plug 评分的肽是否模型打分更高 | 相关性报告（探索性） |
| TUnA 基线 | 同数据训练对比 | 我方 AUC 不低于其 ±0.02（或说明差异原因） |
| 8M MVP | 同数据同协议 | 650M 应优于 8M，量化提升幅度 |

### 3.6 成药性过滤（候选清单的 6 维评估）
1. 预测概率/亲和力（模型输出+不确定性）
2. 拓扑稳定性（LassoPred plug 评分/环长合理性）
3. 合成可行性（长度、Cys 数（二硫键）、非标氨基酸占比、质量<2.5 kDa）
4. 理化性质（亲水性/净电荷/半衰期预测：ProtParam 类工具）
5. 靶标成药性（靶标是否为已知药物靶家族：GPCR/激酶/蛋白酶/E3 等；靶标结构口袋明确性）
6. 新颖性（该肽-靶对是否已有文献/专利报道——查 SciFinder/PubMed）

### 3.7 湿实验验证建议（交付给组员/合作方）
- **A 级候选**（结构锚点支持 + 模型高分）：建议 SPR/BLI 测结合动力学 + 细胞功能实验（ETB 拮抗、PlexinB1 信号等）
- **B 级候选**（同源迁移支持）：建议先 ITC 验证结合，再功能
- **C 级候选**（纯预测）：只进清单，标注"需对接/结构二次确认"
- 每条候选给出：表达/合成来源建议（lasso 肽需前体+成熟酶或化学合成）、阳性对照、预期 IC50 量级

### 3.8 实用性报告的必备内容清单
- 100 对打分矩阵热图（附证据等级标注）
- Top 候选卡片（每张：结构图、打分、成药性 6 维、验证建议）
- 已知对回溯验证表
- 消融瀑布图 + 注意力案例图
- 局限声明（训练数据偏倚：thrombin 类占比、组成级信号占比、体外-体内差异）
