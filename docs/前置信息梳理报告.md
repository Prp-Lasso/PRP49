### 2.3 数据库字段（26 列）
`LP_ID, Original_ID, Query_GI, Peptidase, Phylum, Lasso_Peptide_Family, Lasso_Peptide_Name, Leader_Sequence, Core_Sequence, Precursor_Sequence, Calculated_Lasso_Mass, Number_of_Cys_in_Core, Core_Length, Leader_Length, Precursor_Length, Leader_Core_Ratio, PDB_ID, PDB_link, Ring_Length, Isopeptide, Loop_Length_1/2/3, Upper_Plug_1/2/3`

**关键点**：每条记录都带 LassoPred 预测的拓扑注释（Ring_Length / Isopeptide 位置 / Loop_Length ×3 / Upper_Plug ×3）——可直接用作"环依赖"消融分析（思路 4）与注意力对齐标签（思路 2）的结构先验。

### 2.4 统计画像
- 4749 条 core 序列全部 unique；4636 条 unique precursor
- core 长度 12–160 aa（均值 24.1）
- 49 个家族注释（4442 条未标注家族）；门分布：Pseudomonadota 1803 > Actinomycetota 1314 > Bacillota 881 > Cyanobacteriota 213 > Bacteroidota 189 …
- 二硫键：0 Cys 4114 条；2 Cys 380 条；1 Cys 175 条
- 28 条有实验 PDB 结构（即 LassoPred 训练集 Table S5 的 47/52 条之外的少量标注）

### 2.5 LassoPred 工具本身
- `LassoPred/predict.py`：输入序列 → 预测 3 个候选 3D 结构 + MD 输入文件
- 模型组成：ESM-2 650M per-residue 特征 → k-mer 切分（ring/loop/tail）→ iso_model / plug_model（sklearn，`construc_package/*.pkl`）预测异肽键位点与 plug 位置 → 几何构造 + MD 优化
- 依赖 Amber + PyMOL（Linux，python 3.10）；序列要求 12–~60 aa，第 7/8/9 位必须含 E/D
- **官网 API**（`lassopred.accre.vanderbilt.edu/api/data/`）从本机访问返回 403（疑似地域限制）→ `LassoPeptideClassifier/data_pipeline.py` 的在线下载路径需改用本地 `lassopred_database.csv`

## 3. LassoESM 嵌入器

- **论文**：Mi, X. et al. *LassoESM: a tailored language model for enhanced lasso peptide property prediction*. **Nat Commun 16, 8545** (2025), [10.1038/s41467-025-63412-3](https://doi.org/10.1038/s41467-025-63412-3)
- **模型**：基于 ESM-2 650M 的 MLM 继续预训练（Lasso 肽特异语言模型），hidden=1280
- **HuggingFace**：`ShuklaGroupIllinois/LassoESM`（对比基线 `ShuklaGroupIllinois/PeptideESM2_650M`、`facebook/esm2_t33_650M_UR50D`）
- 架构（已核验 `LassoESM_hf/config.json`）：`EsmForMaskedLM`，33 层 × 20 头 × hidden 1280（= esm2_t33_650M），rotary PE，vocab 33；config 记录训练时 transformers **4.40.1**（仓库 environment.yml 写 4.35.2，建议按 4.40.x 装以兼容该权重）
- 下游任务 3 个：底物耐受性（FusA）、环化酶-肽配对（Cross-Attention）、抗菌活性（Ubonodin/Klebsidin）——均"embedding + 小型分类器"
- 环境：Linux conda env（python 3.10，torch 2.1.0，transformers 4.35.2）；仓库内 `environment.yml` 为 Linux 版本，**本机 Windows Python 3.14 不兼容，需新建 conda/venv (py3.10)**
- **本地模型下载**：正在下载至 `LassoESM_hf/`（`model.safetensors` 2.6 GB；已跳过 1.8 GB 的 optimizer.pt）
- 用法（`code/LassoESM/get_embeddings_LassoESM.py`）：`AutoModelForMaskedLM.from_pretrained(...)` → 取 last hidden state 均值 = 序列嵌入

## 4. 两个 PRP 项目仓库现状

### 4.1 LassoPeptideClassifier（分类器，已完成）
- 架构：FASTA → ESM-2（冻结，默认 t12_35M）→ Conv1D×3 → MultiHeadAttention → MLP → 概率
- 数据：正样本 = LassoPred API（4029 条）；负样本 = UniProt 细菌 Swiss-Prot 40–100 aa（排除 lasso 家族）；CD-HIT（阈值 0.5）去重；负样本降采样至 3× 正样本；80/10/10 分层划分
- 训练：BCEWithLogitsLoss（类别加权）、AdamW、CosineAnnealing、早停；支持 multi_seed/CV/grid
- 该仓库解决的是"序列是不是 Lasso 肽"的二分类，**不是**肽-蛋白互作

### 4.2 PRP49（LPI 回归，雏形）
- 模型（`PRP49_lpiLasso.py`）：`BindingEnergyPredictor`
  - 蛋白侧：ESM-2（默认 t6_8M，可微调）
  - 肽侧：**LassoESM**（加载本地 `./LassoESM` 路径，默认冻结，可解冻末层）
  - 融合：**BAN 双线性注意力**（v=protein, q=lasso）+ MLP 回归头
  - 损失：MSE（回归结合能）
- 数据（`PRP49_dataset.py`）：**Autodock Vina 对接生成的标签** —— 从 `.pdbqt` 解析 CA 序列 + `REMARK VINA RESULT` 能量；蛋白序列从 `pro520.tsv` 查得 → `out.csv`（protein seq / lasso seq / energy）
- 现状问题（已在代码中可见）：
  1. 硬编码路径 `C:\autodockvina\prp49\...`（本机不存在）
  2. 训练标签 = 对接能，本质是"拟合 Vina 打分"而非实验互作
  3. 无测试集/独立评估、无交叉验证、无注意力可视化
  4. `lassoesm_unfreeze=1` 只解冻最后一层
  5. 数据量取决于对接规模（520 蛋白 × N 肽）

### 4.3 与用户 4 个思路的映射
| 用户思路 | 现有基础 | 缺口 |
|---|---|---|
| 1. 小样本过拟合 / 迁移学习 + 数据增强 | LassoESM 已在 7700 条 RODEO 语料上预训练；PRP49 已用 LassoESM 冻结骨干 | 数据增强（环区理性突变）尚未实现 |
| 2. 注意力可解释性 / 结构先验对齐损失 | BAN 已产出注意力图 `att_maps`（`PRP49_ban.py` 返回第 2 个值）；数据库自带 Ring/Isopeptide/Loop/Plug 拓扑注释 | 未接 AF-Multimer 接触图；"注意力对齐损失"未实现 |
| 3. 负样本不可靠 / 结构互补性预筛 + PU 学习 | 目前用 Vina 对接能（连续标签），无"正/负"二值 | 需引入灰色样本策略与 PU 加权 |
| 4. 环依赖消融评估 | 数据库含 Isopeptide 位点（E/D）→ 可自动生成"开环"突变体（E→S） | 评估脚本未实现 |

## 7. 关键结论速览

1. **数据已齐**：4749 条带拓扑注释的 Lasso 肽数据库 + 7700 条 RODEO 语料 + 48 条实验结构 + 28 条带 PDB 的库内条目，全部落盘于工作区。
2. **模型已齐**：LassoESM（HF 权重下载中）+ ESM-2 系列 + LassoPred 结构预测器（可离线跑，缺 Amber/PyMOL）。
3. **PRP49 已有雏形**：双编码器 + BAN 回归，但数据标签是 Vina 对接能、无评估体系、路径硬编码——是"演示级"代码，需重构为可复现 pipeline。
4. **三条路线可用**：
   - A（最小改动）：沿用 PRP49 双编码器架构，把 Vina 标签换成结构化构建的 LPI 数据集（正=已知互作，负=PU/灰色样本），补齐评估。
   - B（基座复用）：把 LassoESM 作为肽编码器接入 TUnA 式 Transformer 框架微调。
   - C（结构先验）：用数据库自带拓扑注释 + AF-Multimer 接触图做注意力对齐与环依赖消融（对应思路 2/4）。
