# PRP49 · 改进方案：让模型"读靶"（靶条件化）

> 2026-09-18 起 · 目标：把模型从"记住哪些肽好"改造为"判断肽与靶是否匹配"
> 起因：零样本探测显示模型对未见靶**完全不读靶**（靶间方差仅 **0.2%**，肽间 99.7%）

---

## 一、诊断（三项，均有数据支撑）

### 1.1 现象

| 证据 | 数值 |
|---|---|
| 真实复合物验证（5 肽 × 11 靶）| 肽间方差 **62.8%** · 靶间 **0.7%** |
| 零样本三靶（GUK1/SSX1/EXOSC1）| 肽间 **99.7%** · 靶间 **0.2%** |
| 对照：真实复合物 MccJ25×RNAP | logit **9.902**（而未见靶最高仅 1.227）|

### 1.2 三个候选根因（逐一检验）

| 假设 | 检验结果 | 判定 |
|---|---|---|
| **H1 编码器严重不对称** | 靶 `esm2_35M`：hidden 480 / 12 层 / **136 MB**；肽 `LassoESM`：hidden 1280 / 33 层 / **2609 MB** → **相差 19 倍** | ✅ **成立** |
| **H2 缺少"同肽×异靶"负样本** | `train_pairs_hard` 中 **264/318（83%）**的肽同时有正负靶 | ❌ **推翻**（监督早就存在）|
| **H3 靶的特异性信号太稀** | 每靶正样本**中位数仅 2 个**（min 1 / max 124）；正负比 1:8.2 | ✅ **成立，且最致命** |

**根因链**：
```
每靶仅 ~2 个正样本  →  学不到"什么靶适合什么肽"
                    →  退化为"记住哪些肽好"（肽身份常数）
                    →  输出与靶无关（0.2% 靶间方差）
```

> H2 被推翻这一点很重要：**问题不是"没给模型配对监督"，而是"给出的靶太少、每靶样本太薄"**。

## 二、两个实验（各自独立验证一个根因）

### 2.1 P0-1：扩大靶覆盖广度

| 项 | 值 |
|---|---|
| 数据集 | `affinity_cls_wide.csv`：2,778 对 / **362 靶** / 1:1 平衡 |
| 对照基线 | A+C `affinity_cls_pairs.csv`：2,462 对 / **218 靶** → **0.6430** |
| 协议 | 按靶分组（`group_col: prot_id`）**完全一致**，唯一变量是靶数 |
| 预登记判据 | ≥0.70 → 靶覆盖是瓶颈；<0.65 → 瓶颈在每靶样本数 |

**为什么用靶内 z-score 而不是绝对阈值**：该数据集是已知结合物的集合（pAffinity 中位 6.82），
绝对阈值（≥6 正 / ≤4 负）只剩 243 个负样本、**仅 37 个靶**同时有正负 —— 覆盖反而更窄。

**结果（fold 0）**：
```
fold 0: AUC 0.729   vs A+C 基线 0.6430   →  +0.086  ✅ 超过 0.70 门槛
```
⏳ 其余 4 折运行中（每折约 3.2 小时，8h 时限内可能只完成 2–3 折）

### 2.2 P0-3：改用配对排序损失

| 项 | 值 |
|---|---|
| 动机 | BCE 可被"肽身份常数"满足；配对损失问"**对这条肽，真靶是否比诱饵靶得分高**"，**不读靶无法满足** |
| 数据 | `train_pairs_hard.csv`（264 肽有配对监督；宽数据集只有 146/2044，故不用）|
| 损失 | `relu(margin − (s_pos − s_neg)) + 0.5 × BCE anchor` |
| 评估 | 按靶分组 AUC + **pair-acc**（0.5 = 瞎猜）|

**首次运行失败**：`CUDA OutOfMemoryError`（配对损失每 batch 两次前向，两份激活同时驻留）。
**修复**：`batch_size 16→8` 且 `max_len 1024→512`（靶平均 283 aa，仅 14% 的靶会截断）。

**同协议基线**（新增 `targetrank_baseline.py`）：用发布的 checkpoint 在**同一套按靶折**上评估
→ 否则只能与 A+C 的 0.6430 跨数据集比较，会把"损失变化"与"数据变化"混在一起。

**结果**：⏳ 运行中

## 三、筛选环节发现的两个方法学问题（已修正）

### 3.1 跨靶对接分**不可比**（严重）

```
靶间对接分系统性偏差：DPP4 −17.3 … DRD2 +6.4   → 跨度 23.7 kcal/mol
靶内标准差中位数：0.92 kcal/mol
→ 靶间偏差是靶内信号的 26 倍
```

**后果**：用全局 z-score 融合时，首版短名单 TOP 10 **全是 DPP4 / PREP** —— 因为这两个靶对
**所有**肽都给低分，这是**口袋性质**，不是肽特异性。

**修正**：两路信号都做**靶内标准化**；并剔除 9 个 clash 正值（DRD2 的 std 高达 44.8，会污染标准化）。

**修正后阳性对照（靶内排名 / 13）**：

| 对 | 文献等级 | 排名 |
|---|---|---|
| **MccJ25 × POLR2A** | C | **1/13** |
| **Anantin × NPR1** | **B（Kd 0.6 µM）** | **2/13** |
| RES-701-1 × EDNRB | **B（IC50 10 nM）** | 4/13 |
| Capistruin × POLR2A | C | 4/13 |
| RES-701-3 × EDNRB | **A（9KDF 电镜）** | 5/13 |

**信号互补性**：`corr(binding_z, dock_z) = +0.103` → 两路信号近乎正交，融合有意义。

### 3.2 排名语义 bug（自查发现）

`rank_target` 曾是 **650 行内的全局排名**，却被按"靶内排名"解读 → 出现 `110/13` 的荒谬数字。
已改为 `groupby(target_id).rank()` 并**加断言**（排名不得超过该靶的肽数）。

### 3.3 仍然存在的缺陷：肽偏置（必须在交付中标注）

```
RES-701-1  在 15 个靶上排第一
MccJ25     在 10 个靶上排第一
Lariocidin  在 7 个靶上排第一
```

**一个肽在多个无关靶上都排第一，更可能是"肽身份常数"而非真实多靶结合**。
短名单必须据此标注，不能把 RES-701-1 的 15 个"第一"当作 15 个独立候选。

## 四、下一步与判据

| 优先级 | 动作 | 成功判据 |
|---|---|---|
| **P0** | P0-1 完成更多折 | 均值 ≥0.70 → 靶覆盖是瓶颈（fold 0 已达 0.729）|
| **P0** | P0-3 出结果 | **pair-acc 显著 >0.5** 且按靶 AUC 优于同协议基线 |
| **P0** | **决定性检验** | 用 P0-3 的 ckpt 重跑零样本三靶 → **靶间方差是否从 0.2% 上升** |
| P1 | 若两者任一有效 | 用新模型重跑 50 靶筛选，替换交付短名单 |
| P1 | 靶编码器升级（H1）| 35M → 650M 对称架构（未做，成本最高）|

> **为什么"零样本靶间方差"是最强判据**：CV 数字可能被数据集特性影响，
> 而"对一条肽给出不同靶不同分数"是"读靶"的**操作性定义**，无法伪造。
