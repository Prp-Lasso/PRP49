# 三个潜在靶点调研：GUK1 (Q16774) · SSX1 (Q16384) · EXOSC1 (Q9Y3B2)

> **文档定位**：组员提出这三个 UniProt 条目"可能有潜力"。经核实，它们是**完整的人类蛋白质**
> （188–197 aa），**不是肽** —— 因此本文从**靶点（target）**角度做系统评估：
> 疾病关联是否成立、成药性证据有多强、以及**与 PRP49 的 Lasso 肽平台是否匹配**。
>
> 核实日期：2026-09-17 · 数据源：UniProt / RCSB PDB / 文献（引用见文末）

---

## 摘要：核实结论

| 靶点 | 疾病关联 | 成药性（小分子）证据 | **与 Lasso 肽平台的匹配度** | 综合 |
|---|---|---|---|---|
| **GUK1** | ✅ 线粒体 DNA 耗竭综合征 21；肿瘤生长/存活 | ✅✅ **已有抑制剂共晶 AT8001（1.76 Å）** + 14 个结构 + 过渡态模拟 | 🟡 核苷酸口袋偏小，更适合小分子 | **最强**（但未必适合肽）|
| **SSX1** | ✅ 滑膜肉瘤（SS18::SSX1 融合）；X 连锁精子发生障碍 | 🟡 仅核小体冷冻电镜（3.02 Å），**无药物样配体** | 🟢 **蛋白–蛋白/染色质界面 → 大环肽的经典适用场景** | **平台匹配度最高** |
| **EXOSC1** | ✅ 脑桥小脑发育不全 1F（PCH1F）| ❌ 8 个结构全为大型复合物，无药物样配体 | 🟡 支架蛋白，界面大而平坦 | 最难 |

**一句话**：**三者都是合理的靶点候选，但"靶点合理"与"适合 Lasso 肽"是两件事** ——
GUK1 成药性最强却偏小分子；SSX1 成药性证据最弱却**最符合大环肽的作用模式**；
三者**共同的硬约束是都在胞内**（见第四节）。

## 一、GUK1 / Q16774 —— 鸟苷酸激酶

### 1.1 基本事实
| 项 | 值 |
|---|---|
| 基因 | **GUK1** |
| 长度 | 197 aa |
| 功能 | GMP + ATP → GDP + ADP；cGMP 代谢；光感受器中 cGMP 循环 |
| 结构域 | Guanylate kinase-like（4–186），Pfam **PF00625** |
| 定位 | 细胞质/胞质溶胶；**线粒体**；光感受器内段 |

### 1.2 疾病关联
- **线粒体 DNA 耗竭综合征 21**（UniProt 疾病注释）
- UniProt 功能注释明确提到"**可能参与某些肿瘤的存活与生长进展**（PMID:31201273）"
- 出现**临床变异 S37P 的晶体结构（9JAE）** → 该变异被结构工作跟进，说明有遗传学关注

### 1.3 成药性证据（**三者中最强**）
```
8PTS   1.76 Å  human GUK1 in complex with compound AT8001   ← 已有抑制剂共晶
9JAB   2.75 Å  过渡态模拟：ADP + GMP + Mg²⁺ + K⁺ + AlF₄⁻      ← 反应机理清晰的酶
9JAH   2.80 Å  GMP + ATPγS + K⁺
9JAI   2.30 Å  GMP + ADP
9JAC   1.47 Å  GMP（最高分辨率）
9JAE   3.00 Å  S37P 突变体
（共 14 个条目，2024–2025 年密集新增）
```

**判读**：**AT8001 的存在证明该靶点可被小分子占据** —— 这是成药性最硬的证据。
加之 1.47–1.9 Å 的高分辨率结构群与过渡态模拟，**活性位点的几何与化学已相当清楚**。

### 1.4 与 Lasso 肽的匹配性 —— **偏差**
- GUK1 的药效团是**核苷酸结合口袋**（ATP/GMP），通常**浅而带电**
- 大环肽/拓扑肽的优势在于占据**大而平坦的 PPI 界面**，而非深埋的辅因子口袋
- 197 aa 的单结构域酶**缺少供大环肽锚定的扩展表面**
- **结论**：GUK1 是**好靶点**，但**用 Lasso 肽打它不是最优选择** —— 除非目标是
  **变构位点**或**蛋白–蛋白界面**（如 GUK1 与其 1 个注释互作伙伴之间）

## 二、SSX1 / Q16384 —— 滑膜肉瘤融合蛋白

### 2.1 基本事实
| 项 | 值 |
|---|---|
| 基因 | **SSX1** |
| 长度 | 188 aa |
| 功能 | 可能的转录调节因子；参与精子发生 |
| 结构域 | KRAB-related（20–83），Pfam **PF09514** |
| 定位 | 细胞质；细胞骨架；**鞭毛轴丝** |

### 2.2 疾病关联（**最强**）
- **滑膜肉瘤**：标志性 **SS18::SSX1 融合**（染色体易位）→ UniProt 标注 **Proto-oncogene**
- **X 连锁精子发生障碍 5**
- 2025 年 *Nature Communications* 报道：**靶向 SUMOylation 可稳定 cBAF 复合物并破坏 SS18::SSX 转录程序**
  → **说明该靶点仍在活跃的药物研发视野内**

### 2.3 成药性证据（**弱**）
```
8HR1   3.02 Å  Cryo-EM: SSX1 bound to the unmodified nucleosome   ← 唯一结构
```
- **无任何小分子/药物样配体**
- SSX1 是**染色质结合蛋白**，通过**大尺度蛋白–蛋白界面**发挥作用
- 传统小分子难以处理这类界面 → **这正是"undruggable"靶点的典型形态**

### 2.4 与 Lasso 肽的匹配性 —— **最契合** ✓
- SSX1 的作用方式是 **蛋白–蛋白 / 蛋白–染色质界面识别**
- **大环肽与拓扑异构环肽恰恰是这类界面的天然"化学抗体"**：
  刚性的环状骨架提供大的接触面积与预组织构象，且蛋白水解稳定性高
- 已有先例：Lasso 肽 **MccJ25 抑制 RNA 聚合酶**（同样是大型核酸酶复合物的界面抑制剂）
- **结论**：**若本项目的目标是"用 Lasso 肽打一个难成药靶点"，SSX1 是最合乎逻辑的候选**

## 三、EXOSC1 / Q9Y3B2 —— RNA 外泌体组分 CSL4

### 3.1 基本事实
| 项 | 值 |
|---|---|
| 基因 | **EXOSC1**（别名 CSL4）|
| 长度 | 195 aa |
| 功能 | RNA 外泌体复合物**非催化**组分；3'→5' 外切核酸酶活性所必需 |
| 结构域 | S1 motif（66–147）；Pfam **PF14382 / PF10447** |
| 定位 | 核/核仁；细胞质 |
| 互作 | **14 个注释伙伴**（外泌体核心）|

### 3.2 疾病关联
- **脑桥小脑发育不全 1F（PCH1F）** —— 2025 年有新生儿**纯合变异**病例报告
- 神经退行相关（UniProt 关键词：Neurodegeneration）

### 3.3 成药性证据（**最弱**）
```
9G8P/9G8O/9G8N/9G8M   3.3–7.0 Å   与 40S/80S 核糖体、SKI2 的复合物
6H25                  3.8 Å       EXO-10-MPP6 复合物
6D6Q/6D6R             3.45 Å      外泌体–MTR4–RNA 复合物
2NN6                  3.35 Å      人 RNA 外泌体核心（Rrp41/45/46/43/Mtr3/42/Csl4/Rrp4/6）
配体：仅 ZN / MG / ANP（辅因子与核苷酸类似物）——**无药物样小分子**
```
- **全部是大型复合物结构**，EXOSC1 在其中是**结构支架**
- 无药物样配体 → 成药性证据最弱

### 3.4 与 Lasso 肽的匹配性 —— **困难**
- 作为支架蛋白，其功能依赖**与 14 个伙伴的装配** → 若要抑制，需**破坏复合物装配**
- 但装配界面通常**大、平坦、且分散**，缺乏单一高亲和力热点
- 且外泌体是**必需管家复合物** → 抑制的**选择性窗口窄**（正常细胞也会受害）
- **结论**：EXOSC1 作为**药物靶点**的优先级最低；作为**疾病机制研究**对象更有价值

## 四、三者共同的硬约束：**都是胞内靶点**

这是评估中最关键、也最容易被忽略的一点。

| 靶点 | 定位 | 对肽类药物的含义 |
|---|---|---|
| GUK1 | 细胞质、**线粒体**、光感受器 | 需穿细胞膜（线粒体还需穿双层膜）|
| SSX1 | 细胞质、细胞骨架、**细胞核/染色质** | 需穿膜 + 入核 |
| EXOSC1 | **细胞核/核仁**、细胞质 | 需穿膜 + 入核 |

**现状**：
- **绝大多数肽类药物靶向细胞表面受体或胞外域**（本项目的 11 个靶中，EDNRB/NPR1 是
  细胞表面 GPCR/受体，PLXNB1 是表面受体，其余多为胞内或分泌蛋白）
- **Lasso 肽有胞内作用的天然先例**：MccJ25 经 **FhuA 转运蛋白**进入大肠杆菌并抑制 RNAP
  → 但那依赖**细菌特有的主动摄取系统**，**人类细胞没有对应机制**
- **人细胞内的肽递送**仍是未解决的工程问题（需 CPP、纳米载体、或稳定化改造）

> **因此**：把这三个靶点纳入 PRP49 时，**首要问题不是"模型能否预测结合"，
> 而是"肽能否到达靶点"**。预测一个无法递送的靶点，其应用价值受限。

## 六、建议的评估路径（按优先级）

| 优先级 | 动作 | 理由 |
|---|---|---|
| **P0** | **先回答递送问题**：检索是否有 CPP/大环肽将配体递送至胞内/核内的先例 | 若不可递送，后续预测全部无应用价值 |
| **P0** | **确认组员的信息来源**：这三个号从哪个表来？若是 TUnA 的 `Intra*_rr.txt`，那是**蛋白–蛋白**数据 | 决定它们是"靶点候选"还是"被误读的蛋白" |
| **P1** | 对 **SSX1** 做 Lasso 肽可靶向性分析：定位 SSX1–核小体界面（PDB 8HR1）的可成药子口袋 | 平台匹配度最高，且是真正的 PPI 场景 |
| **P1** | 把三者加入**成药靶对接面板**（复用已有 AF 模型流程）→ 得到 Lasso 肽 × 三靶的对接打分 | 成本低（已有 41 个 AF 模型管线）|
| **P2** | 用现成模型对三者做**零样本打分**（11 条扫描肽 × 3 靶）| 快速看模型是否给出任何信号；注意模型未见过这些靶 |
| **P2** | GUK1 的**变构位点**分析（避开核苷酸口袋）| 若坚持用肽打 GUK1，变构是唯一合理路线 |

## 七、诚实的局限

1. **本文的"靶点潜力"判断基于公共数据库注释**，未做实验验证；疾病关联的强度未做
   遗传学分级（如 ClinVar 证据等级）
2. **AT8001 的化学结构与活性数据未公开获取**（仅知其存在于 8PTS）→ 无法评估其类药性
3. **SSX1 的 8HR1 是 SSX1–核小体复合物**，但药物开发通常针对 **SS18::SSX1 融合蛋白**
   —— 两者不是同一实体，本文的评估适用于野生型 SSX1
4. **胞内递送判断基于当前技术现状**，该领域进展快，结论有时效性
5. 本文**没有**给出"该不该做"的最终建议 —— 这取决于项目目标（见第八节）

## 八、给项目的定位建议

| 若项目目标是 | 建议 |
|---|---|
| **筛出可成药的 Lasso 肽候选** | **优先 SSX1**（PPI 界面 = 大环肽主战场），但必须先解决递送 |
| **扩展模型的人靶覆盖** | 三者都可加入，用**对接 + 零样本打分**低成本试探；**不投入验证资源**（无参考对）|
| **做方法学（肽-蛋白预测）** | 三者的价值在于**新的靶类型**（酶 / 染色质 / 支架）→ 可作为**域外泛化测试集** |
| **寻找新的 Lasso 肽-靶关系** | 应查 **LassoPred 库（4,749 条）** 与此三靶的文献交集，而非从蛋白组随机取 ID |
